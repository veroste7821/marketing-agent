# Kit de lanzamiento de redes sociales — Bravera

Esta carpeta contiene todo el contenido listo para copiar/pegar al crear las cuentas oficiales de Bravera en LinkedIn, Instagram y Threads.

## Contenido de la carpeta

| Archivo | Contenido |
|---|---|
| `linkedin.md` | Datos de página, bio, tagline y 8 posts de lanzamiento listos para publicar. |
| `instagram.md` | Handle, bio, estructura de highlights, 10 posts + 3 guiones de Reels. |
| `threads.md` | Handle, bio y 12 posts cortos/hilos en tono conversacional. |
| `content-calendar.md` | Calendario día por día de las primeras 4 semanas de lanzamiento, referenciando los posts de cada archivo. |

## Lo que falta hacer manualmente

Por seguridad y verificación de identidad, **LinkedIn, Instagram y Threads no permiten crear páginas/cuentas de forma automatizada**. Los pasos siguientes deben hacerse a mano, pero con este kit deberían tomar minutos:

### 1. LinkedIn — Página de empresa
1. Ir a **https://www.linkedin.com/company/setup/new** (requiere iniciar sesión con una cuenta personal de LinkedIn).
2. Elegir "Empresa pequeña" como tipo de página.
3. Completar con los datos de `linkedin.md`: nombre "Bravera", URL `braverasoft`, tagline, sector "Desarrollo de software", tamaño y ubicación.
4. Pegar la bio de la sección "Acerca de".
5. Subir el logo de perfil y el banner (ver sección de imágenes más abajo).
6. Publicar el primer post (LI #1) el mismo día de creación de la página.

### 2. Instagram — Cuenta de empresa
1. Crear la cuenta desde la app de Instagram, o gestionarla desde **https://business.instagram.com/** si se quiere vincular a una página de Facebook/Meta Business Suite.
2. Usar el handle `@braverasoft` (verificar disponibilidad; si está tomado, usar `@braverasoft.dev` o `@braverasoft_oficial` como alternativa y actualizar este documento).
3. Configurar como cuenta profesional/empresa, categoría "Empresa de tecnología de la información".
4. Pegar la bio de `instagram.md` y el link en bio.
5. Subir foto de perfil y, si aplica, destacados (highlights) según la sección "Estructura de feed / Highlights".

### 3. Threads
1. Ir a **https://www.threads.net/** (o desde la app de Threads).
2. Threads se crea vinculado a una cuenta de Instagram existente — por eso conviene crear primero Instagram.
3. Usar el mismo handle `@braverasoft` para mantener consistencia entre redes.
4. Pegar la bio de `threads.md`.

## Consistencia de handle

Usar `@braverasoft` como handle en las tres redes. Si alguno está tomado, documentar la alternativa elegida en el archivo correspondiente (`linkedin.md`, `instagram.md` o `threads.md`) antes de empezar a publicar, para que todo el kit quede alineado.

## Imágenes de perfil y banner

Las imágenes de perfil (logo/isotipo) y banners para las tres redes están siendo generadas en paralelo por otro proceso y van a quedar disponibles en:

```
/home/user/marketing-agent/brand-assets/social/
```

No es necesario crear estas imágenes manualmente ni desde este documento: solo hay que revisar esa carpeta una vez que el otro proceso termine, y subir los archivos correspondientes a cada red (foto de perfil cuadrada para Instagram/Threads, foto de perfil + banner horizontal para LinkedIn).

## Orden recomendado de lanzamiento

1. Crear las tres cuentas el mismo día (o con máximo 1-2 días de diferencia) para evitar inconsistencias de handle.
2. Subir las imágenes de perfil/banner desde `brand-assets/social/` en cuanto estén disponibles.
3. Publicar el primer post de cada red (LI #1, IG #1, TH #1) siguiendo el orden sugerido en `content-calendar.md`, Semana 1.
4. Seguir el calendario de `content-calendar.md` para las siguientes 4 semanas.
